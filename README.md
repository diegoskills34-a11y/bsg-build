# BSG Bestiario + Crónica — Rebirth 2.6

Repositorio de compilación para la DLL propia del Bestiario/Crónica.

La GitHub Action descarga el servidor dedicado oficial de 7 Days to Die mediante SteamCMD para obtener las DLL de referencia de la versión actual; esas DLL del juego no se guardan en este repositorio.

El artefacto de CI contiene `bsg_BestiaryChronicle.dll`.
