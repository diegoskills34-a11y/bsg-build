The new classifier reads the XML identity first, falls back to class ID lookup, never guesses from C# type. A past single 'Demolicion salvaje' legacy kill stored under EntityZombieCopRebirth is migrated once to zombieDemolitionFeral and bsg_demolisher. Ambiguous aggregates remain untouched. PlayerTitles progress stays intact. Demo kills count in both bsg_demolisher and general bsg_infected (matching the existing overlapping family rules).
